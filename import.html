Recomendaciones de Formato

  • 1. Las columnas deben mantener los nombres estándar (RUT, NOMBRE, SUPERVISOR, ESTADO) para que el sistema las reconozca automáticamente.
  • 2. El archivo debe estar en formato .XLSX o .CSV (UTF-8) para evitar errores de caracteres especiales.
  • 3. Para Agendamientos: Los estados válidos son RECHAZADO (negativo), EJECUTADO (positivo) y EJECUTADOCONLLAMADO (positivo).
  • 4. El sistema cruza automáticamente los RUTs con la dotación vigente para asignar supervisores.
